# INVENTORY-MANAGEMENT-SYSTEM
The Inventory Management System is a web-based application designed to simplify and automate inventory-related operations. It allows users to efficiently manage products, categories, suppliers, purchases, sales, and stock levels from a centralized platform. The system helps maintain accurate inventory records, monitor stock availability identify low-stock products, and keep track of inventory transactions. It reduces manual work, improves data accuracy, and provides an organized way to manage day-to-day inventory operations. This project demonstrates practical implementation of database management, CRUD operations, user management, and web application development.

Features

User registration and secure login
Add, update, and delete products
Manage product categories
Track available and low-stock products
Manage suppliers
Record sales and purchases
Automatic stock quantity updates
Search and filter products
Inventory transaction history
Dashboard with inventory statistics
Admin/user role management
Database-driven inventory management

Technologies Used

Frontend: HTML, CSS, JavaScript
Backend: Java / Spring Boot
Database: MySQL
Version Control: Git & GitHub

Objective

The main objective of this project is to provide a simple, efficient, and user-friendly solution for managing inventory digitally. It reduces manual work, improves stock accuracy, and provides quick access to important inventory information.
